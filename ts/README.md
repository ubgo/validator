# @ubgo/validator

The TypeScript runtime for schemas generated by [`github.com/ubgo/validator`](https://github.com/ubgo/validator). Author validation once in Go; run the same rules in the browser.

## What it does

- Validates a value against the JSON Schema the Go emitter produced, via Ajv (draft 2020-12 or draft-07, detected from `$schema`).
- Implements [Standard Schema](https://standardschema.dev) (`~standard.validate`) and Standard JSON Schema (`~standard.jsonSchema`), so it drops into tRPC, TanStack Form, React Hook Form and Hono without adapters.
- Honors the portability manifest: rules the schema cannot carry are never silently ignored. Opaque rules warn once and run server-side; async rules round-trip to the backend, debounced, during `validateAsync`.
- Reports issues with the same codes, paths and message templates as the Go `verr` package, so one message catalog serves both sides.

## Usage

```ts
import { createValidator } from "@ubgo/validator";
import { userSchema, userManifest } from "./user.schema"; // validatorctl ir export --ts user.schema.ts

// The value type is inferred from the const schema; pass <T> explicitly for a JSON import.
const user = createValidator(userSchema, { manifest: userManifest, baseURL: "https://api.example.com" });

const local = user.validate(input);            // sync, JSON Schema rules only
// { ok: false, issues: [{ code: "min", path: "$.age", message: "must be at least 18", ... }] }

const full = await user.validateAsync(input);  // + server round-trips for async rules
```

With any Standard Schema consumer (Hono is exercised in this package's tests; tRPC and TanStack Form consume the same interface):

```ts
app.post("/users", sValidator("json", user), (c) => c.json(c.req.valid("json"))); // Hono
const form = useForm({ validators: { onChange: user } });                          // TanStack Form
```

## Server round-trips

For each manifest entry of class `server`, `validateAsync` POSTs `{ rule, value }` to the entry's endpoint and expects `{ ok: true }` or `{ ok: false, issues: [{ code, message }] }`. Calls for the same rule within `debounceMs` (default 300) collapse into one request; every caller receives the result of the last value. The backend is always authoritative: these calls are UX, and the Go `Validate()` on submit is the decision.

## Options

| Option | Purpose |
|---|---|
| `manifest` | The portability manifest emitted with the schema. Pass it whenever one exists. |
| `onNonPortable` | Hook per entry the browser cannot run. Default warns once via `console.warn`. |
| `serverRules` | Enable server round-trips. Default: true when the manifest has server entries. |
| `baseURL` | Prefix for relative endpoints. |
| `debounceMs` | Round-trip debounce window. |
| `fetch` | Custom `fetch`. |
| `ajv` | Extra Ajv options merged over the defaults. |
